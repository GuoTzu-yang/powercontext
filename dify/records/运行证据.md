## R3 · PowerContext 侧记录（读写与检索）

### R3.1 健康检查（scope 映射）
```
GET http://<PowerContext>:8099/health
→ 200 {"ok":true,"scopes":{"story":"scp_53pfqc9h8aaavxwxm2f2w627b5",
                           "dify-eco-dify-tester":"scp_39tcrr5r2c0x5739vnthqdc73n"}}
```
→ 可见应用按 `dify-<user_id>` 建立了独立 scope。

### R3.2 写入 → 检索闭环（独立探针，不经 Dify）
```
POST /remember {"scope":"eco-evidence","text":"证据探针：玩家带着一盏不会熄灭的铜灯"}
→ 200 {"ok":true,"scope_id":"scp_0t1cffa34cpkxwrc8yz8zf140r"}

POST /search   {"scope":"eco-evidence","query":"铜灯","limit":3}
→ 200 {"hits":["证据探针：玩家带着一盏不会熄灭的铜灯"]}
```
→ 证明桥接的 `/remember` → `/search` 语义闭环成立（FTS 命中原文）。

### R3.3 检索为空的反例
```
POST /search {"scope":"dify-demo-user","query":"铜灯","limit":5}      → {"hits":[]}
POST /search {"scope":"dify-demo-user","query":"带了什么","limit":5}  → {"hits":[]}
```
→ 与「该 scope 从未写入」一致，说明 scope 隔离有效、不会串味。
