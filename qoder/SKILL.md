# SKILL: StudyFlow 科研与学习效率工作台

## 用途

面向学生与科研人员的轻量效率工具，解决三件高频痛点：

1. **专注难**——长任务缺乏节奏，容易被打断后无法回到状态；
2. **读论文低效**——读完就忘，缺少可检索的结构化笔记；
3. **笔记不可迁移**——资料散落在各工具里，无法导出复用。

StudyFlow 把「番茄专注计时」和「论文速读结构化卡片」放进同一个单页，数据只存本机，
可一键导出 JSON / Markdown 接入 Obsidian、Notion 或论文综述写作。

## 能力

| 能力 | 说明 |
| --- | --- |
| 番茄专注 | 1–180 分钟可调，开始/暂停/重置，完成后自动累计番茄数与专注分钟数 |
| 速读卡片 | 背景·问题 / 方法 / 结论 / 局限·可追问 四栏结构，强制把论文拆成可复用的判断 |
| 本地持久化 | localStorage 存储，无账号、无网络请求、无隐私外泄 |
| 导出 | JSON（结构化，便于脚本处理）与 Markdown（便于写作与知识库归档） |
| 卡片库 | 倒序展示、单条删除、一键清空，带计数 |

## 使用方式

单文件、零依赖、零构建：

- 在线：GitHub Pages 托管页面直接打开
- 离线：下载 `index.html` 双击即可，无需服务器

## 技术要点

- 纯 ES5 语法 + IIFE 封装，不依赖任何框架与 CDN，弱网/离线可用
- `localStorage` 读写全部包 try/catch，配额或隐私模式下降级为内存态并提示，不白屏
- 所有用户输入经 HTML 转义后插入 DOM，避免 XSS
- 计时器用 `setInterval` + 秒级 tick，暂停/重置均清理句柄，避免多计时器叠加
- 导出走 `Blob` + `URL.createObjectURL`，用完 `revokeObjectURL` 释放
