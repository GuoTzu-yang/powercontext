# StudyFlow · 科研与学习效率工作台

让学习、科研和工作更高效的轻量工具：**番茄专注计时 + 论文速读结构化卡片 + 一键导出**。

单文件、零依赖、零构建，数据只存在本机浏览器。

## 快速上手

在线打开（GitHub Pages）：

```
https://guotzu-yang.github.io/powercontext/qoder/
```

离线使用：下载本目录的 `index.html`，双击用浏览器打开即可，无需服务器与网络。

## 功能

- **番茄专注**：时长 1–180 分钟可调，开始 / 暂停 / 重置；完成后自动累计番茄数与专注总时长。
- **论文速读卡片**：按「背景·问题 / 方法 / 结论 / 局限·可追问」四栏记录，逼自己把论文读成可复用的判断。
- **卡片库**：倒序列表、单条删除、一键清空。
- **导出**：JSON（便于脚本处理）与 Markdown（便于写综述、入知识库）。

## 为什么是这几个功能

读论文的真正成本不在「读完」，而在**读完之后能不能被检索、被复用**。
所以卡片用固定四栏而不是自由文本框——结构稳定才能导出成统一格式；
配合番茄钟，把「读一篇」变成可计量的专注单元，避免开了十篇都没读完。

## 隐私

- 无账号体系、无后端、无任何网络请求。
- 所有数据保存在浏览器 `localStorage`，清空浏览器数据即彻底删除。
